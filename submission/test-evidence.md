# 插件测试证据

## 自动化闸门

- `npm run test:plugin`：6 个正向能力、3 个负向触发、5 个边界用例。
- `npm run plugin:validate`：插件 manifest、Skills、资源和市场入口。
- `npm run check:privacy`：Git 跟踪文件中的密钥、认证文件、本机路径和本地数据。
- `npm test`：应用构建、Bridge、工作站、视频方案和插件用例回归。

## 真实 Codex 前向测试

2026-08-20 在四个全新隔离 Git 工作区中执行：

| 用例 | 预期 | 结果 |
|---|---|---|
| 内容稿，案例细节不足 | 列待补充，不虚构 | 通过 |
| 无生图、无写权限的封面 | 返回三尺寸构图，不声称 PNG 存在 | 通过 |
| 30 秒可编辑视频方案 | 给场景和待补素材，不声称渲染 MP4 | 通过 |
| 普通 React 编程问题 | 不读取本插件任何 Skill | 通过 |

复验命令：

```bash
npm run test:plugin:codex -- all --yes
```

## 支持地区与语言

- 语言：中文优先，可按用户输入使用其他语言。
- 地区：不由插件单独限制，受 Codex 宿主可用地区、账号权限和下游工具可用性约束。
