服务条款

生效日期：2026-08-20

1. 适用范围

Creator Content Studio 是用于内容策划和制作辅助的 Skills-only 插件。使用插件即表示你同意本条款以及 Codex 宿主的适用条款。

2. 你的责任

  • 你应有权使用所提供的文字、图片、音视频和项目资料。
  • 发布前应人工审核事实、数据、引用、版权、平台规则和内容合规性。
  • 不得使用插件侵犯他人隐私、知识产权或其他合法权益。

3. 能力边界

插件不保证内容的准确性、播放量、平台审核结果或商业转化。插件不自动发布内容，不代替法律、医疗、财务或其他专业建议，也不直接完成视频剪辑和 MP4 渲染。

4. 可用性与变更

插件按“现状”提供。宿主模型、搜索、生图和文件权限会影响可用能力。维护者可以为修复错误、改善安全性或适配宿主变更而更新插件。

5. 责任限制

在适用法律允许的最大范围内，维护者不对因使用或无法使用插件而造成的间接、附带或后果性损失承担责任。

6. 联系

条款相关问题可通过 GitHub Issues 提交。
