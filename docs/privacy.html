Privacy

隐私政策

生效日期：2026-08-20

本政策说明 Creator Content Studio（“插件”）如何处理你为内容创作任务提供的信息。

1. 插件处理的信息

插件会处理你主动提供的账号定位、选题、受众、内容稿、案例摘要、素材和制作要求。请不要提供 API Key、密码、身份证明或不必要的客户私密数据。

2. 数据用途

这些信息仅用于完成你当前请求的内容稿、HTML、封面方案、已选平台文案或视频场景计划。插件不使用这些内容建立广告画像。

3. 存储与传输

插件是 Skills-only 软件包，不运营独立后端、账号数据库或分析服务。你的请求由 Codex 宿主环境处理，文件只在宿主允许且你请求创建时写入当前工作区。Codex 宿主的数据处理与保留受其自身政策和你的账号设置约束。

4. 可选的第三方能力

只有在你的请求需要且当前宿主提供时，插件才可能使用网络搜索或图片生成能力。实际数据处理受对应工具提供方政策约束。能力不可用时，插件应如实返回降级方案。

5. 你的选择

你可以不提供可识别个人、客户或项目的信息；可以在提供前做匿名化；也可以删除本地工作区中的生成文件。

6. 联系方式

如有隐私问题，请通过 GitHub Issues 联系 Content Workstation 维护者。
