# Visual production rules

## Shared rules

- Start from accepted copy and preserve its meaning.
- Use only assets supplied by the user, generated during the task, or licensed for reuse.
- Keep visual hierarchy readable at the requested size.
- Verify every reported artifact exists and matches its requested format.

## Recording HTML

- Use semantic HTML and responsive CSS.
- Make every section understandable without hovering.
- Keep remote dependencies at zero unless the user explicitly requests otherwise.
- Match the narration order when the accepted script includes a recording timeline.
- Avoid dense dashboards when a diagram or a few decision cards communicate the point better.

## Covers

- Prefer one short primary title, one focal subject, and one supporting visual cue.
- Use high contrast and large title type for waterfall feeds.
- Protect safe areas independently for 16:9, 4:3, and 3:4.
- Avoid tiny UI screenshots, excessive badges, long subtitles, and decorative text that competes with the title.
