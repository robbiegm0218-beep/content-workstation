# Selected-platform publishing packages

Generate packages only for platforms the user explicitly selected. One selected platform means one package, not a default four-platform bundle.

## Shared fields

For each selected platform provide:

- Recommended title and up to two alternatives when useful
- Description or post copy
- Searchable tags or topics
- One discussion question or pinned-comment prompt
- One restrained call to action aligned with the creator's goal

Preserve the approved thesis across platforms. Adapt format and density, not the conclusion.

## Bilibili

- Use a specific, searchable title that promises a clear problem, judgment, or method.
- Provide a structured description suitable for a longer video.
- Include chapter suggestions only when the content has clear sections.
- Make the discussion question invite professional experience, not empty engagement.

## Xiaohongshu

- Use compact, conversational copy with a strong first-screen takeaway.
- Prefer scan-friendly paragraphs or short bullets.
- Use relevant topic tags without keyword stuffing.
- Avoid promising results that the evidence does not support.

## WeChat Channels

- Keep the title and description concise and trustworthy.
- Make the opening sentence understandable without platform jargon.
- Use a discussion prompt that works in an acquaintance-network context.

## Douyin

- Lead with conflict, consequence, or a practical mistake.
- Keep the description short and compatible with fast consumption.
- Do not distort a nuanced professional conclusion into an absolute claim merely for clicks.
